How to use this workbench

All signals here are synthetic benchmark stimuli generated locally. Nothing is measured from hardware.

  1. Pick a preset or adjust the signal, filter and analysis controls.
  2. Every plot redraws immediately from the real DSP engine in src/dsp.cjs.
  3. Hover or use arrow keys on a plot to probe exact numerical values.
  4. Export the experiment as JSON, CSV, C header or a WAV file of the filtered signal.

Keyboard: arrow keys move the frequency probe, Home/End jump to DC/Nyquist, Enter pins it, Escape releases it. Press Space on a focused button to activate it.
